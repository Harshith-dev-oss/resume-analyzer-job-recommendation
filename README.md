# AI-Based Resume Analyzer & Job Recommendation System

An AI-based resume analysis and job recommendation system developed using Java, Spring Boot, MySQL, HTML, CSS, and JavaScript.

## Features

* Resume information analysis
* Skill and keyword matching
* Job recommendation
* Job match percentage
* Missing skill identification
* REST API integration
* MySQL database storage
* Web-based user interface

## Technologies Used

* Java
* Spring Boot
* Spring Data JPA
* MySQL
* HTML
* CSS
* JavaScript
* REST API
* Maven

## Project Flow

User enters resume details → Spring Boot REST API → Resume analysis → Skill matching → Job comparison → Match score → Skill gap identification → Job recommendations

## How to Run

1. Clone the repository.
2. Open the project in VS Code or IntelliJ IDEA.
3. Configure MySQL in `application.properties`.
4. Create a database named `resume_analyzer`.
5. Run the Spring Boot application.
6. Open `http://localhost:8080` in your browser.

## Project Purpose

The purpose of this project is to analyze resume information, identify relevant skills, compare them with job requirements, calculate job matching scores, and recommend suitable job roles.
